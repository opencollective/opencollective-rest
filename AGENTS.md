# opencollective-rest

Express REST wrapper around the GraphQL API (Apollo Client, TypeScript, Babel). Prefer this for legacy HTTP integrations; new platform logic belongs in `opencollective-api`.

## Quality

From this repo: `npm run type:check`, `npm run lint:quiet`, `npm run prettier:check` (fix: `prettier:write`). Tests: Jest (`npm run test`). Schema: `npm run graphql:update` (API must be running).
